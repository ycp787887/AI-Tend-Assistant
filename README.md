# 标书智能助手 — 从 Demo 到可交付产品的全栈实践

AI 驱动的投标文件合规预审工具，覆盖从“招标公告”到“分析报告”的全流程。

## 技术栈
- **前端框架**：Streamlit
- **AI 模型**：DeepSeek API (OpenAI 兼容)
- **Agent 框架**：LangGraph 状态图 + 自定义工具调用
- **文件处理**：pikepdf / qpdf (加密解锁)、Tesseract (OCR)、pypdf (文本提取)
- **数据存储**：SQLite (历史记录)、磁盘缓存
- **其他**：Pydantic 结构化输出、向量检索 (RAG)

## 踩过的最深的三个坑

### 1. OCR 后文件字节流被覆盖，分析时报错
- **现象**：OCR 识别成功后，点击比对报 `UnicodeDecodeError`
- **原因**：OCR 结果写入 `tender_file_bytes` 后，分流器重新检测文件头，把纯文本当 PDF 判为格式无效
- **解决**：引入 `_ocr_done_flag` 标记，在比对时跳过 PDF 文件头校验，直接解码 UTF-8 文本

### 2. Streamlit 两个 `with st.sidebar:` 块互相覆盖
- **现象**：文件上传后侧边栏的按钮全部消失，只剩文件预处理状态
- **原因**：Streamlit 的渲染机制中，后一个 `with st.sidebar:` 会覆盖前一个的内容
- **解决**：合并两个侧边栏块为一个，把所有按钮和状态显示放在同一个 `with` 块内

### 3. `session_state` 缺少初始化导致页面跳回阶段一
- **现象**：OCR 完成后页面自动跳回“还没报名”阶段，文件上传框消失
- **原因**：`st.radio` 的 `key="bidding_stage"` 未在 `init_session_state` 中初始化，`st.rerun()` 后重置为默认值
- **解决**：在 `init_session_state` 的 `defaults` 字典中增加 `"bidding_stage"` 的初始值

## 架构设计的关键决策

### 文件预处理分流器
从简单的 `if/elif` 文件头检测，演进为支持 OCR/解密/直接读取三种路径的状态机。 关键设计：通过 `_last_text_extraction_key` 标记避免重复检测，同时兼容 `st.rerun()` 后的状态恢复。

### Agent 工具调用机制
独立于 LangGraph 的轻量级路由系统。`classify_intent` 用 AI 识别用户意图，`try_handle_with_tool` 根据意图调用对应工具函数。 优势：不需要函数调用 API，兼容任何模型；工具函数完全独立，不依赖 Agent 状态。

### “不硬解”的设计哲学
发现 .SDTF/.HYZF 等专用格式必须由平台官方工具打开后，主动放弃硬解路线，改为指引用户正确操作流程。 启示：不是所有问题都要用代码解决，知道“这个该由平台工具处理”本身就是正确的产品逻辑。

## 如果重来一次，我会怎么设计
1. **先把入口做成对话式**，而不是后来才从 radio 表单改成 Agent 分流
2. **session_state 管理从第一天就用一个集中的 init 函数**，避免到处 `if "xxx" not in st.session_state`
3. **文件预处理和侧边栏渲染解耦**，避免两个 `with` 块互相覆盖的问题
4. **先做全流程测试用例**，再叠加功能，减少回归 bug

## 技术亮点
- **缓存 + RAG 降本**：同一文件不重复调 API，RAG 只传相关段落，Token 消耗降低约 60%
- **优雅降级**：AI 不可用时用正则兜底，保证产品在任何情况下都能跑通
- **流式输出**：全部 AI 调用采用 `stream=True`，用户可见逐字生成，告别等待转圈
- **结构化输出**：Pydantic 定义格式，Instructor 保证 100% 正确，消除 JSONDecodeError
- **指数退避重试**：API 失败自动重试 3 次，等待时间逐次翻倍（1s→2s→4s）

---

## 已知限制
- 专用格式 (.SDTF/.HYZF 等) 无法直接解析，需引导用户使用平台官方工具
- 打印报告受浏览器安全策略限制，无法通过 `window.close()` 自动关闭窗口
- OCR 依赖本地 Tesseract 和 Poppler 安装，首次部署需手动配置
- Agent 工具调用目前为关键词 + AI 意图识别混合模式，后续可升级为纯 LangGraph ToolNode
