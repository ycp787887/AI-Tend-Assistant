# 投标文件合规预审助手

AI 驱动的投标文件自动比对工具。

技术栈

Streamlit

DeepSeek API

python-dotenv

##开发历程

###0.5->1.0: 从能跑到能用

-最初只是一个能调用API的臃肿的脚本

-发现同一个文件重复分析烧钱，意识到需要缓存


###1.0->2.0：从能用到健壮

-拆分成多个代码模块,添加了代码注释，提升了代码可读性

-实现磁盘缓存，同一文件不重复调用API

- 实现优雅降级，AI挂了也能用正则兜底

- 配置文件集中管理，密钥进 .env


## 健壮性改进

###错误处理优化
- 致命错误（API密钥错误、网络已断开）立即反馈，不浪费时间和token重试
- 清晰的中文错误提示，用户知道下一步该做什么
- 详细的错误提示，维护者知道该怎么优化

### 打印功能
-报告内容用静态HTML页面承载，调用浏览器原生打印输出。
-避开了PDF兼容性问题和Streamlit动态渲染的不稳定性。


### 防呆设计探索

**问题**：用户把标书和公司资质放反 → 浪费API调用 + 结果错误

**尝试**：写AI检测程序自动识别文件类型 → 发现反而多消耗API

**最终选择**：在界面上用醒目文字提示"请确保文件位置正确"

**启示**：不是所有问题都要用AI解决，有时候一行提示比一套算法更有效。


###指数退避重试
API调用失败时自动重试三次，等待时间逐次翻倍（1秒->2秒->4秒)
应对网络短暂波动，避免一次就超时就中断分析


###实现实时展示打字机效果

- 标书提取、公司资质提取、隐藏风险扫描全部改为 stream=True 流式调用
- 用户可见 JSON 逐字生成，告别等待转圈
- 保留原版非流式函数作为兼容备用
- 新增 stream_handler.py 和流式解析函数


## 收获
- 用户操作习惯往往和你想的不一样
- 每次调用API都在烧钱，缓存是必须的
- 降级不是"备选方案"，是"救命方案"


## 版本说明

### v1_original - 原始版本
- 单文件实现，最小可用原型
- 运行：`cd v1_original && streamlit run app.py`

### v2_improved - 健壮化版本
- 模块化架构（9个模块）
- 磁盘缓存（避免重复API调用）
- 指数退避重试机制
- 优雅降级（AI不可用时正则兜底）
- 运行：`cd v2_improved && streamlit run main.py`
